## Context

The Asset Collection Editor handles editing of reusable tile collections used by buildings. There are two distinct patterns to support:

1. **Getter-based collections** (WallHouse, WallManor): Parameters (WALL_SUFFIX, ROOF_SUFFIX) are referenced by tiles via template syntax. Changing a param affects all tiles. Tiles are derived from individual getters.
2. **groupAsset-based collections** (FenceSimple, FencePlatform): Tiles are generated by calling `groupAsset({flatW, cornerW, innerW, isFrise})`. Weight parameters control tile variety.

The preview service runs building generation server-side and returns the result for client rendering.
